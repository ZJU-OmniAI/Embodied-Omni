# Project websites

GitHub Pages publishes this directory from the `main` branch, with no build step.

The EmbodiedMemory-Bench project page is at https://zju-omniai.github.io/Embodied-Omni/EmbodiedMemoryBench/ and its source is in `EmbodiedMemoryBench/`. Update that directory to publish changes. All images, scripts, the English video, and the paper PDF are served from this public repository.

Local preview: run `python3 -m http.server 8000 --directory docs` from the repository root and open `http://localhost:8000/EmbodiedMemoryBench/`.
